# TestBench — Free QA Testing Toolkit

A static, browser-based QA utility website. No server, database, build step, API key, or paid domain is required.

## Included tools
- Test Case Generator
- Bug Report Builder
- JSON Formatter & Validator
- Synthetic Test Data Generator
- API Test Checklist

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser.

## Publish free with GitHub Pages
1. Sign in or create an account at https://github.com
2. Create a new **public** repository, for example `qa-testing-toolkit`.
3. Upload `index.html` and `README.md` to the repository root.
4. Open **Settings → Pages**.
5. Under Build and deployment, choose **Deploy from a branch**.
6. Select branch `main` and folder `/(root)`, then click **Save**.
7. Wait for the deployment. Your site will be available at a URL similar to:
   `https://YOUR-USERNAME.github.io/qa-testing-toolkit/`

## Publish free with Cloudflare Pages
1. Sign in at https://pages.cloudflare.com/
2. Create a Pages project and connect your GitHub repository, or upload the static files using the available direct-upload flow.
3. For a plain HTML site, no build command is needed. Set the output directory to the folder containing `index.html` (usually `/` or the project root, depending on the setup flow).
4. Deploy. Cloudflare provides a `pages.dev` address.

## Important
- All tool logic runs in the browser. The site does not send entered data to a server.
- Do not paste real passwords, tokens, customer data, or production secrets into examples.
- The generated test cases/checklists are suggestions. Review them against your requirements.
- The synthetic email addresses use the reserved `.test` domain.
- This site does not execute API requests or connect to applications.
- Hosting is free within the hosting provider's current terms; a custom domain is optional and usually costs money.
- If you want advertising, apply separately to an ad network once the site has useful content and meets its eligibility policies. Approval and earnings are not guaranteed.
